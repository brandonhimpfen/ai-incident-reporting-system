# Governance

AI incidents should produce operational learning.

## Review Questions

Each incident review should answer:

1. What happened?
2. Who or what was affected?
3. Why did it happen?
4. Was this a one-off failure or a systemic pattern?
5. What changed as a result?
6. How will recurrence be detected?

## Ownership

Each incident should have a responsible owner or team. Possible owners include:

- Product
- Engineering
- AI systems
- Safety
- Security
- Legal or compliance
- Support

## Auditability

Production implementations should preserve:

- Status changes
- Severity changes
- Label changes
- Assignment changes
- Resolution notes
- Corrective actions
- Export history

## Retention

Incident data should be retained only as long as necessary. Sensitive prompts and outputs should be redacted when full text is not required for investigation.
