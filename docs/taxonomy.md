# Taxonomy

This taxonomy provides suggested labels for classifying AI incidents.

## Output Quality

- `hallucination`
- `unsupported_claim`
- `incorrect_citation`
- `stale_information`
- `misleading_answer`
- `low_quality_response`

## Safety and Policy

- `unsafe_output`
- `policy_violation`
- `over_refusal`
- `under_refusal`
- `harmful_instruction`
- `safety_risk`

## Security and Misuse

- `prompt_injection`
- `jailbreak_attempt`
- `tool_misuse`
- `data_exfiltration_attempt`
- `security_risk`
- `user_misuse`

## Privacy

- `privacy_leak`
- `sensitive_data_exposure`
- `personal_data_in_prompt`
- `insufficient_redaction`

## Retrieval and Tools

- `retrieval_failure`
- `irrelevant_context`
- `missing_context`
- `tool_failure`
- `tool_permission_error`
- `agent_action_error`

## Operations

- `system_timeout`
- `rate_limit_failure`
- `logging_gap`
- `monitoring_gap`
- `evaluation_gap`
