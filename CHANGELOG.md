# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-02

### Added

- Initial AI incident reporting framework.
- Incident taxonomy and severity model.
- Incident lifecycle documentation.
- JSON schemas for incidents, events, actions, root causes, and exports.
- PostgreSQL database migrations.
- Example incident reports.
- GitHub issue templates for incident reports and bug reports.
- Security and contribution documentation.
