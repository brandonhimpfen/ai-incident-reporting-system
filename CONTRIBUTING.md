# Contributing

Contributions are welcome.

This project is intended to provide a practical, implementation-ready foundation for AI incident reporting. Contributions should improve clarity, interoperability, reliability, or operational usefulness.

## Good Contributions

Useful contributions may include:

- Improved incident taxonomy entries
- Additional example reports
- Better severity definitions
- Additional JSON schema validation rules
- Database migration improvements
- Documentation improvements
- Implementation examples
- Security and governance refinements

## Contribution Guidelines

Please keep contributions:

- Clear
- Practical
- Vendor-neutral
- Implementation-oriented
- Well-documented

Avoid promotional language, unsupported claims, or vendor-specific assumptions unless they are clearly marked as examples.

## Pull Request Checklist

Before opening a pull request, please confirm that:

- The change has a clear purpose.
- Documentation has been updated where needed.
- JSON examples remain valid.
- SQL migrations are readable and reversible where practical.
- New taxonomy entries are broadly useful, not overly narrow.

## Reporting Issues

Use the GitHub issue templates when reporting problems, suggesting improvements, or proposing additions.
